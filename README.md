# Stateful-VirtualEngine (Mock Server)

Программный комплекс для динамической виртуализации API-сервисов с поддержкой управления состоянием (Stateful), изоляцией тестовых сессий и системой мониторинга инцидентов.

## Архитектура системы
Система состоит из четырех компонентов, запускаемых в изолированной среде Docker:
1. **Backend (FastAPI):** Ядро маршрутизации и логики управления состоянием.
2. **Frontend (React Dashboard):** Веб-интерфейс для управления правилами и анализа логов.
3. **MongoDB:** Документоориентированное хранилище состояний и истории транзакций.
4. **Redis:** In-memory хранилище для управления сессиями и контроля лимитов (Rate Limiting).

## Начало работы (Запуск системы)

### Требования
- Docker Engine 24.0+
- Docker Compose v2+

### Инструкция по запуску
1. Убедитесь, что Docker Desktop запущен.
2. В корневой директории проекта выполните команду:
   ```bash
   docker-compose up -d --build

### После завершения сборки образов сервисы будут доступны по следующим адресам:
- Frontend (Dashboard): http://localhost:5173
- Backend (API): http://localhost:8000
- API Documentation (Swagger): http://localhost:8000/docs

## Остановка проекта

Для остановки всех контейнеров выполните:
   ```bash
   docker-compose down


## Информация для разработчиков

- Бэкенд реализован на Python (FastAPI).
- Фронтенд реализован на React (TypeScript + Tailwind CSS).
- Управление зависимостями осуществляется через requirements.txt (backend) и package.json (frontend).
- Логирование транзакций настроено асинхронно с использованием фоновых задач FastAPI.
